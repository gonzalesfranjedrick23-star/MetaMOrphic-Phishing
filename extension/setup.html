Protection Setup

To provide real-time protection, CyberSentinel needs permission to:

  • ✓Monitor browser navigation Detect the page you open so it can be checked (URL only).
  • ✓Analyze URLs and page security characteristics Sends the URL - and, only if the content filter is on, the page title and a short visible-text sample - to the local CyberSentinel backend. No passwords, form values, cookies or full page content.
  • ✓Block phishing websites Redirect the tab to a CyberSentinel warning page when a page reaches the blocking threshold.
  • ✓Watch downloads for obviously-malicious files Runs a quick URL/filename check and can cancel a clearly malicious download. The background agent performs the full on-disk scan.
  • ✓Show security notifications Desktop notification when a download is blocked.
  • ✓Apply optional content-filtering rules Off by default. You choose which categories to block.

CyberSentinel runs locally. It does not disable your antivirus, does not install hidden persistence, and does not collect browsing history or credentials. You can turn protection off any time from the toolbar popup.
